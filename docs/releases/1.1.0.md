# CoronaSDR 1.1.0 — release candidate (build 9)

Prepared on 2026-11-06. This is a draft source release, with a separately built local App Store distribution package. It has not been published, submitted to App Store Connect or qualified on physical hardware.

## Changes

- Receive foreground CW text and FT8 messages, with monitoring mute, bounded history, message details, freeze and sharing.
- Keep CW listening pitch independent of the selected carrier, and keep decoder audio independent of speaker timing and playback effects.
- Preserve I/Q alignment and timing across split network packets, buffer overruns and processing boundaries.
- Improve FT8 recovery with bounded reliability retries, decoded-signal subtraction and finer timing. The recorded corpus now yields 23/24 original annotations, up from 17/24, plus seven independently reproduced messages.
- Improve large-text receiver controls and spectrum labels; allow vertical scrolling over the spectrum while retaining horizontal tuning.

## Validation

- Fresh release-source runs: 26/26 optimized decoder tests and 122/122 app unit tests passed.
- The earlier functional-code validation passed all 26 host tests under Address Sanitizer and Thread Sanitizer, the C address/undefined-behavior checks, and both interface test methods on iPhone and iPad simulators in separate runs. A 90-window host soak produced identical results on every cycle. Release preparation changed only source formatting and version metadata.
- A signed arm64 Release archive and local App Store export succeeded. The exported package reports 1.1.0 (9), passes strict signature verification, carries an Apple Distribution signature, disables debugger attachment and is not restricted to registered devices.

The detailed evidence, reproduction commands and limits are in [Decoder validation](../DECODER-VALIDATION.md).

## Remaining release work

- **Decoder quality:** one original FT8 annotation and two additional WSJT-X reference outputs remain missed. Broader independent signal/noise coverage and recorded hand-keyed/Farnsworth CW testing remain pending. These are software/corpus gaps; hardware is not inherently required to investigate them.
- **Physical iPhone/iPad:** sustained decoding speed, dropped windows, memory, heat and battery; speaker/USB/Bluetooth routes, interruptions, lock/background behavior; local-network permission and reconnection; VoiceOver and touch, including the mute switch thumb. The existing Bluetooth A2DP issue [#15](https://github.com/s1lviu/CoronaSDR/issues/15) remains unresolved.
- **Receiver and RF:** supported tuner/server combinations, HF/direct sampling, offset/gain/clipping and clock errors; calibrated sensitivity/selectivity with controlled input.
- **Toolchain and distribution:** runtime testing at the iOS 18 minimum, plus App Store Connect validation, metadata/privacy declarations and review. Current simulator evidence is from iOS 27.2.

No WSJT-X-equivalent sensitivity, calibrated SNR, transmitter timing accuracy or sender authentication is claimed. App Store distribution is separate from this source release.
